# deep-etymology-zh

用中文深度讲解英语单词、句子翻译、中文英译与语法问题，并默认把词源学作为核心分析路径。
**单词之为什么是这一单词，为什么大家这样用，为什么它长这样————将词源学和词语形态从不甚方便的工具变成对话框和笔记的处理工艺。**

让单词变成这样：
```logseq
- superstition
  - 音标 : /ˌsuːpərˈstɪʃən/ (美) ; /ˌsuːpəˈstɪʃən/ (英)
  - 词性与核心义 : n. 迷信
  - 词源骨架 : super- (在上/超过) + stare (站立) → stāre → stat- → statiō → superstitiō
  - 原子构词 : super- (超出) + stat- (站，过去分词词干) + -iō (抽象名词后缀)
  - 核心意象 : “站在上面”→ 抽象的形而上概念或神明等高高居于现实生活之上。
  - 例句 : Superstition often arises from a lack of understanding. 迷信常源于缺乏理解。
  - 同源词 : superstare (拉丁语“站在上方”) ; stable, station, statue
```

## 功能概述

本技能将英语学习与词源分析深度融合，帮助学习者理解 **单词长什么样子——它有五官，有表情**。理解单词 **为什么** 是现在的意思，而不仅仅是 **是什么** 意思。适用于：

- 英文单词词源、词根词缀、拉丁/希腊构词和日耳曼词根、词义演变、同源词比较
- 英文句子语法拆解与翻译
- 中文句子英译及近义词辨析
- 语法结构的深层解释
- 处理包含多个英文 block 的 Logseq 页面，并同步生成去重后的记忆卡（`___card.md`）

## 核心原则

1. **默认中文回答**，词源优先
2. **拆到最小可解释单位**，不满足于“来自拉丁语/希腊语”
3. **最大化解释单词本身的形态、语义图像和演变**，而非强行拉长时间链
4. 对拉丁语派生词，始终解释变形部分的语法身份和语义添附
5. 对希腊语派生词，明确结合元音、化合物结构等
6. 不确定的词源明确标注，不强行精确
7. 处理 Logseq 页面时，按 block 拆分，正确生成引用与卡片。斜体卡片生成反向中文测英文卡。

## 适用输入类型

| 输入类型 | 输出内容 |
|----------|----------|
| 单个英文单词 | 音标、词性、核心义、词源链（PIE → 英语）、原子化构词、形态变化细讲、核心意象、现代释义+例句、同源词、总结 |
| 英文句子 | 中文翻译 → 句法结构分析 → 关键词解释（如有必要） |
| 中文句子 | 最合适的英文翻译 + 语域/自然度/精确性说明 |
| 语法问题 | 结构在句中的作用 + 与相近结构的对比 |
| Logseq 页面（多 block） | 逐 block 解析，合并同源变体，添加 `意义接近的词` 引用，可选生成 `___card.md` 卡片 |

## 输出特色

- 对拉丁语形式（如 `testis`, `versus`, `perfectus`, `statio`）明确说明其语法形态（分词、动名词、抽象名词等）及语义贡献
- 主动回答“这真的是根形式吗？”“这个拉丁/希腊变形意味着什么？”
- 支持四档深度分配（A 长文 / B 紧凑 / C 简注 / D 纠错）
- 每个单词回答末尾附带 **Logseq 摘要块**（代码块内为可直接粘贴的日志格式，不含表格或普通段落）

## 使用要求

- 本技能为 AI 行为指南，无需安装额外软件
- 用户只需在对话中引用该技能名称（如“使用 deep-etymology-zh”）或直接按技能风格提问即可
- 对于 Logseq 页面处理，需要用户提供原始内容（可粘贴或上传文件）。但大批量处理会有解析深度较低的质量问题，已尽量优化，但对于个别词仍然需要手动查询。

## 与其他工具的配合

- 推荐配合 [Logseq](https://logseq.com/) 使用，生成的摘要块与 `___card.md` 可直接导入
- 词源优先引用 [Etymonline](https://www.etymonline.com/) 作为参考来源
